Core Engineering Pillars

1. Strict Anti-Tamper & Zero Secrets

Operates strictly via metadata and Win32 process handle enumeration. Never reads or parses contents inside ~/.ssh, ~/.aws, or tokens. Safe to run in production enterprise settings.

2. Local-First Architecture

Snapshots are stored in an append-only local SQLite database with 30-day auto-pruning. No telemetry is sent to third-party clouds unless explicitly requested by the user for Gemini AI analysis.

3. Deep Cyber-Forensic AI

Integrated with Google Gemini API (gemini-3.6-flash / 3.7-flash) to synthesize plain-English risk assessments, process intentions, infostealer threat vectors, and copyable PowerShell fix commands.

Live Forensic Case Study: AWS Credential Drift

CRITICAL CREDENTIAL ACCESS DRIFT
Observed State: initialized (perms: 777)
Resource Target C:\Users\solob\.aws
Accessor / Trigger Filesystem / AWS CLI Initialization
1. What This Program / Resource Is

Stores plaintext credentials (aws_access_key_id and aws_secret_access_key), config profiles, and session tokens utilized by the AWS CLI, boto3, Terraform, and IDE cloud plugins.

2. Real-World Security Impact

Targeted by infostealers (RedLine, Lumma, Vidar). Broad Windows permissions allow malicious packages or background processes to exfiltrate keys, leading to cloud infrastructure hijacking, S3 data exfiltration, or rogue IAM backdoor creation.

3. Automated Remediation Command (Provided by Gemini) 
# Lock ACLs to current user only & strip broad group permissions:
icacls "C:\Users\solob\.aws" /inheritance:r /grant:r "solob:(OI)(CI)F"
icacls "C:\Users\solob\.aws" /remove "NT AUTHORITY\Authenticated Users" /remove "Everyone"

Technical Architecture & Stack

Backend Core (Python 3.14)

  • • Scanner: WindowsSecurityScanner (Win32 API handle inspection, psutil net connections, 10s budget).
  • • Engine: Risk rules engine with customizable risk_rules.json and heuristic cross-workspace detection.
  • • Storage: Embedded append-only SQLite (snapshots.db) with automated 30-day retention pruning.
  • • API Layer: Flask 3.1 REST API with async background thread jobs and response times under 100ms.
  • • AI Analyzer: Google GenAI SDK (google-genai) with zero-latency thinking budget overrides.

Frontend (Vite 8 & React 19)

  • • Type Safety: Strict TypeScript implementation (src/types/drift.ts).
  • • 3D Aesthetics: Three.js interactive Torus Knot wireframe background with particle sparks & mouse lerping.
  • • Styling: High-contrast industrial design system powered by Tailwind CSS v4.
  • • Visuals: SVG Blast Radius arc gauge, canvas historical sparklines, and expandable diff cards.
  • • Modals: Opt-in active port probe modal and Gemini AI posture assessment reports.

How to Run & Verify

1. Start the Local Web & API Server: 
python backend\app.py
# Open http://127.0.0.1:5000 in your browser
2. Run via Standalone Git-Style CLI: 
python cli.py scan --baseline   # Set initial clean state
python cli.py diff              # Output color-coded terminal drift
3. Configure Optional Gemini AI Threat Analysis: 
# Set in PowerShell or save in local .env file (strictly git-ignored):
$env:GEMINI_API_KEY="your_api_key_here"
4. Automated Background Scans (Windows Task Scheduler): 
powershell -ExecutionPolicy Bypass -File .\scripts\schedule_task.ps1 -Action Install -IntervalMinutes 30
