# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of PermissionDrift very seriously. Because this tool inspects local process permissions and sensitive credential metadata, any potential privilege escalation, denial of service, or unintended data disclosure is treated with the highest priority.

To report a vulnerability:
- Please open a **GitHub Security Advisory** directly on the repository or contact the maintainers.
- Include detailed reproduction steps and affected operating system version.
- Please allow reasonable time for a patch before public disclosure.
